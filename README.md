# Museum Mannequins 1.0.0

Poseable mob and animal displays with an optional glass case.

Craft a mannequin from an armor stand, white wool and oak planks. Place it and right-click with an empty hand to edit. Enter a living vanilla mob ID such as minecraft:pig, minecraft:cow, minecraft:wolf or minecraft:zombie. Configure body rotation, head rotation, head tilt, frozen limb position and standing, sitting, crouching, sleeping or swimming pose. Pose support follows each mob's vanilla renderer. Use a glass block on the display to add a case. Sneak-right-click empty-handed to remove the case. The placing player and server operators may edit the mannequin. Its selected mob and pose are retained in the dropped item.

## Installation

Minecraft Java 26.3, Java 25, Fabric Loader 0.19.5 or later, and Fabric API 0.163.0+26.3 or later. For singleplayer, install the JAR and Fabric API on the client. For multiplayer, install matching versions on the server and every client.

English and Russian translations are included. Build with JDK 25 using `bash gradlew build` or `gradlew.bat build`.
